Question Scanned (Offline OCR)

A 2kg block slides down a 30 degree incline with kinetic friction coefficient 0.2. Find the acceleration.

S
I don't know where to start. Which formula should I use for this problem?
iQ
SOCRATIC GUIDE Before picking a formula, let's identify what the textbook gave us. What quantities do you already know?
S
Given: Mass $m = 2\text{ kg}$, angle $\theta = 30^\circ$, kinetic friction $\mu_k = 0.2$.
iQ
SOCRATIC GUIDE Spot on! Now think about the forces. Which component of gravity pulls the block down the slope?
S
The parallel component along the incline: $mg \sin\theta$.
🎯 Student Turn: What should we identify first?
iQ
CONCEPT UNLOCKED Brilliant! Kinetic friction opposes motion with $f_k = \mu_k mg \cos\theta$.
Now combine them into Newton's 2nd Law: $ma = mg\sin 30^\circ - \mu_k mg\cos 30^\circ$.
Notice mass cancels out: $a = g(\sin 30^\circ - 0.2\cos 30^\circ) = 3.20\text{ m/s}^2$!
